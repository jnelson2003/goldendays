GOLDEN DAYS WEBSITE STARTER
===========================

This is an original responsive website template inspired by the STRUCTURE and ENERGY
of major festival websites such as ACL Festival. It does not copy ACL's proprietary code.

FILES
-----
index.html    Main page
styles.css    All styling and responsive layouts
script.js     Sticky nav, mobile menu, reveal animations
images/       Add your Golden Days images here

REQUIRED IMAGE FILENAMES
------------------------
hero.jpg
parade.jpg
street-fair.jpg
duck-race.jpg
collage-1.jpg
collage-2.jpg
collage-3.jpg
collage-4.jpg
duck-hero.jpg

BEST IMAGE SIZES
----------------
hero.jpg:        2200 x 1400 px or larger
event cards:     1400 x 1600 px
collage photos:  1400 x 1000 px
duck-hero.jpg:   2200 x 1300 px

QUICK EDITS
-----------
1. Open index.html.
2. Search for "GOLDEN DAYS IS COMING" to change the announcement bar.
3. Search for "THE BIG EVENTS" to edit event cards.
4. Search for "YOUR GOLDEN SCHEDULE" to edit event times.
5. Replace logo placeholders under "MADE POSSIBLE BY" with sponsor <img> tags.
6. Replace the newsletter form action="#" with your Constant Contact signup endpoint.
7. Replace placeholder social links in the footer.
8. In styles.css, the brand colors are all at the top under :root.

HOSTING
-------
This can be hosted as a normal static site on Netlify, Cloudflare Pages, GitHub Pages,
or a subdomain such as goldendays.fairbankschamber.org.

If you are embedding into ChamberMaster/GrowthZone rather than using a standalone site,
the HTML should be broken into embed-friendly sections and the CSS should be scoped
to a wrapper so it does not collide with the Chamber theme.
